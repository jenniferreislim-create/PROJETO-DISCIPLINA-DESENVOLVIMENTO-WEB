# BiblioGest - Sistema de Gestão de Biblioteca
Aplicação web desenvolvida em Python/Django para o gerenciamento de acervo, leitores e histórico de empréstimos de livros.
# Como executar o projeto localmente
# 1. Pré-requisitos
* Python 3.10 ou superior instalado.
# 2. Passo a Passo
1. Aceder à pasta principal do projeto Django:
```bash
cd Biblio_Gest
1. Ativar o ambiente virtual (.venv):
•	No Windows (PowerShell):
..\.venv\Scripts\Activate.ps1
2. Instalar as dependências necessárias:
pip install django dj-static
3. Executar o servidor de desenvolvimento:
python manage.py runserver
5. Aceder à aplicação no navegador: 
Abra o endereço: http://127.0.0.1:8000/
